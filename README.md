# KCEM 공예 데이터 에디터

공예 추천 데이터와 재료 난이도를 관리하는 웹 에디터입니다.

## 배포

Settings → Pages → Deploy from a branch → main → /(root) → Save.

## 최초 이관

관리자 계정으로 로그인한 뒤 ‘최초 이관’에서 로컬 export.json을 선택합니다. 페이지를 새로고침하고 다시 로그인하여 90개 목록을 확인한 뒤 ‘키오스크에 게시’를 누릅니다.

export.json은 이 저장소에 업로드하지 않습니다. 키오스크는 시작할 때 게시본을 내려받고 실행 중에는 로컬 데이터를 사용합니다.
